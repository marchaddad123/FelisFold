# FelisFold visual references

The nine PNGs are design-only references supplied by Mark for the October 2026 editorial rebuild. They guide composition, photography density, section rhythm and typography. They are not sources for medical facts, cat ancestry, product details, people, dates or Lotus history.

They were moved from `public/design-references/` before the production build. Nuxt does not deploy this documentation directory. Never render, preload, index or use these PNGs as website media.

Production content uses the existing researched source records, real Mark/Lotus photographs, original SVG illustrations and independently licensed photographs.
